## 📖 About The Project

This project started as a standard school assignment to build a text-based game. However, on my own initiative, I decided to take it a step further. To meet the academic requirements of a console-based application while making the gameplay much more engaging and unusual, I implemented a **hybrid interface**. 

You can interact with the game visually by clicking GUI elements, while core commands and logic are still handled via the classic text console. 

### ✨ Key Features
*   **Hybrid Gameplay:** Best of both worlds! Click through the graphical UI for quick actions, and type in the console for complex commands.
*   **Minecraft Theme:** Explore, gather resources, and survive in a text-driven blocky universe.
*   **Educational Foundation:** Built from scratch in Java as a school project to demonstrate object-oriented programming principles and UI/Console integration.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites
Make sure you have the following installed on your machine:
*   [Java Development Kit (JDK)](https://www.oracle.com/java/technologies/downloads/) (Version [Podaj wersję Javy, np. 17] or higher)
*   [IntelliJ IDEA](https://www.jetbrains.com/idea/download/) (Community or Ultimate edition)

### ⚙️ Installation & Execution

**1. Download the project:** 
Clone the repository using your terminal:
```bash
git clone https://github.com/AirNicolas54382/Minecraft2.0
```
*(Alternatively, simply download the `.zip` file from GitHub and extract it to your preferred folder).*

**2. Launch IDE:** 
Open **IntelliJ IDEA**.

**3. Load the project:** 
Click on **Open** and select the extracted project folder.

**4. Wait for setup:** 
Allow IntelliJ a moment to index the files and configure the Java SDK.

**5. Find the main file:** 
In the *Project Explorer* (usually on the left), navigate to the `src` folder and locate the `Main.java` file.

**6. Run the game:** 
Right-click on `Main.java` and select **▶ Run 'Main.main()'**.
